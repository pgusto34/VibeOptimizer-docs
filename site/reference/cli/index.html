CLI commands

These tables are generated from the registered Typer command tree, including help and paired boolean flags. null is a literal parser default: the launcher may resolve an effective default afterward. See first campaign and resume/recovery. New launches default to automatic GPU placement, 105-minute allocations, partition main, and automatic backend selection. Omitted options on resume retain persisted values. Internal commands are listed for completeness and are not recommended entry points.

vibeoptimizer campaign floor

Section titled “vibeoptimizer campaign floor”

Measure whether this case’s before/after gap clears its own measured noise floor.

Needs the GPU and both reference images, and takes a few minutes per replay. Exits 3 when the case is not resolvable, so a benchmark suite can be swept in a loop.

Argument / optionType / choicesRequiredCLI defaultDescription
--configpath; exists=False; file_okay=True; dir_okay=TrueYesnullCampaign YAML path.
--repsintNo5Replays per image; the spread comes from these.
--marginfloatNo3.0Sigmas the before/after gap must clear.
--publish / --no-publishbooleanNotrueRecord the result in the case.
--jsonbooleanNofalseEmit the canonical report.
--helpbooleanNonullShow this message and exit.

vibeoptimizer campaign trajectory

Section titled “vibeoptimizer campaign trajectory”

Assemble what the agent did, in order, from the attempt’s recorded artifacts.

Writes <output>/trajectories/<campaign>.{json,md} — beside the campaigns, never inside one — and grades the trajectory against the case’s answer key on the controller’s side when the case ships one. Reads only; the campaign store is not touched.

Argument / optionType / choicesRequiredCLI defaultDescription
--campaign-idstrYesnullCampaign identifier.
--jsonbooleanNofalsePrint the trajectory JSON.
--helpbooleanNonullShow this message and exit.
